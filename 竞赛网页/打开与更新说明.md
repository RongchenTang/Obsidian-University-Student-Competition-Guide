# 竞赛网页：打开与更新说明

## 从哪里开始

双击 **`00-开始这里.html`**，用 Chrome 或 Edge 打开，然后从页面里进入其他功能。整个「竞赛网页」文件夹要放在一起，不要单独挪动其中的文件。

| 文件 | 给谁用 | 用途 |
|---|---|---|
| `00-开始这里.html` | 所有人 | 入口页 |
| `01-竞赛查询与奖金计算器.html` | 学生 | 查赛事类别（A/B/待学校确认），估算学校获奖奖励 |
| `02-竞赛日历网页PPT.html` | 课堂投影 | 12 个月竞赛日历、方向推荐、案例、现场互动；内含查询器演示入口 |
| `03-更新数据.html` | 老师 | 修改 Markdown 后重新生成数据 |
| `手机单文件版/竞赛查询器-手机版.html` | 学生手机 | 单独一个文件，发到手机就能打开 |
| `assets/` | 程序用 | `data.js`（数据）、`core.js`（查询和计算规则）、`page-template.js`（生成手机版用） |
| `tools/build.mjs` | 可选 | 装了 Node.js 时，可以用命令行代替第 03 页 |

## 网页 PPT 怎么操作

| 按键 | 作用 |
|---|---|
| → / ↓ / 空格 / PageDown | 下一页 |
| ← / ↑ / PageUp | 上一页 |
| Home / End | 第一页 / 最后一页 |
| Q | 跳到「查询器现场演示」页 |
| F | 全屏 |
| T | 深色 / 浅色切换 |

演示页左侧嵌入了真实的查询器，上方有 4 个一键演示按钮。在查询器里打字时，方向键归查询器用；要翻页时按 PageUp / PageDown（翻页笔一般就是这两个键），或者先点一下查询器以外的地方。

## 学生怎么在手机上用

把 `手机单文件版/竞赛查询器-手机版.html` 通过微信或 QQ 发给学生，学生用手机浏览器打开即可。这个文件已经把数据打包在里面，不依赖其他文件。

> 微信内置浏览器打开本地 HTML 文件时有时会受限制，可以让学生选「用其他应用打开」，再选系统浏览器。

## 两个网页的数据从哪里来

两个网页**只**读取 `assets/data.js`。这个文件完全由仓库根目录的资料库 Markdown（`重庆移通学院_学科竞赛导航资料库_….md`）生成，读取的部分包括：

- 第二节 2.1：学生奖励表、团队系数、特等奖系数
- 第三节 3.2：12 个月备赛日历
- 第四节、第五节：A 类 80 条、B 类 46 条（编号、名称、方向、承办单位、硬件标注）
- 5.1：C/D 类学校批准记录（目前为空，所以未收录的赛事都显示「待学校确认」）
- 5.2：常见简称与消歧提示
- 7.1：备赛要点
- 第十节：别名、A→B 对应关系、页码、结构化日历节点、方向路线、方向归并、课堂案例、三笔钱

## 修改 Markdown 后怎么刷新两边的数据

**方法一（推荐，不用装任何软件）**
1. 在 Obsidian 里修改资料库 Markdown 并保存。
2. 用 Chrome 或 Edge 打开 `03-更新数据.html`，把 Markdown 文件拖进去。
3. 看检查结果。出现红色「错误」时不会生成数据，按提示改好 Markdown 再拖一次；黄色「提醒」不影响生成，但建议核对。
4. 点「选择『竞赛网页』文件夹并写入」，选中 `竞赛网页` 文件夹，浏览器问是否允许修改时选允许。
   - 如果没有这个按钮（比如用的是 Firefox），就点两个下载按钮，再把 `data.js` 放进 `assets` 文件夹、把手机版放进 `手机单文件版` 文件夹，替换旧文件。
5. 刷新已打开的查询器和网页 PPT。手机版需要重新发给学生。

**方法二（装了 Node.js 时）**

在 `竞赛网页` 文件夹里运行下面的命令。它会自动找到上一级目录里最新的资料库 Markdown：

```bash
node tools/build.mjs
```

## 常见修改怎么做

| 想做的事 | 改 Markdown 的哪里 |
|---|---|
| 学校批准了一个 C/D 类赛事 | 5.1 表格新增一行：学校认定写 `C` 或 `D`，并填写批准部门与文件编号（**不填文件编号不会被认定**） |
| 确认某个 A 类赛事的重庆赛区选拔赛 | 10.2 新增一行，状态写 `已核实`；在此之前，查询器对该层级显示「对应关系待核实」 |
| 新一届比赛公布了日期 | 10.4 新增一行，状态写 `已核实`，填写年份、事项类型和来源链接；同时把对应的「待公布」行删掉 |
| 学生常用的简称搜不到 | 10.1 在对应编号后面加别名，用「、」分隔 |
| 学校发布了新的 A/B 名单 | 改第四、五节表格；编号保持 `A01`、`B01` 这样的格式 |

**注意**：只改表格内容，不要改表头和标题编号（如 `## 四、`、`### 10.4`），否则生成数据时会报「找不到标题」。
